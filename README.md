# EA4 Practicador — Lenguaje Musical

Practicador interactivo de Lenguaje Musical de 4.º curso de enseñanzas elementales (EA4), basado en el libro *Pentagrama 3. Llenguatge Musical* de C. Amat i A. Casanova.

Desarrollado por **El Sindicato EA4**.

## Qué incluye

- Práctica interactiva de los 8 ejercicios del examen:
  1. Síncopas y contratiempos
  2. Transporte
  3. Compás y tonalidad
  4. Intervalos
  5. Completar compás
  6. Escalas
  7. Armadura
  8. Notas extrañas

- Teoría paso a paso con referencia al libro para cada tema
- Temas adicionales: grados tonales, enarmonía, acordes, semitono diatónico/cromático, notas de adorno
- Generador de exámenes aleatorios

## Tecnología

- React + TypeScript (Vite)
- Tailwind CSS
- VexFlow (renderizado de partituras)
- Vitest (tests)

## Instalación local

```bash
cd app
npm install
npm run dev
```
